# 0.0.2 本地发布与规划对照

日期：2026-10-18。范围按用户确认：补齐可本地实现的确定能力，待协商规则保持关闭，验证后提交并打 `v0.0.2` 标签；不推送、不部署生产环境。

本文记录代码交付与证据，不把历史长期建议、待协商业务规则或未执行的生产验收写成已完成。

## 本轮交付

- 合并并验证原工作区 beta16：课程/资料/创作者统一搜索、输入联想与热词、管理端分析、审计 CSV 导出、SSE 未读数及轮询回退。
- 审核与发布分离：通过审核只记录结论；独立发布队列选择明确版本并提交资源修订号。发布再次检查唯一主文件、扫描状态和来源许可；旧公开版本在新版本发布前保留。
- 贡献者暂停、恢复、本人退出：理由与预期状态必填，拒绝越权及过期操作；撤销受托分配，保留本人内容归属、既有合同、收益及购买权益；恢复不自动恢复旧分配。
- 权限采用用户最终决定的精简方案：后台职责权限覆盖全站；资料维护范围单独按课程/资料分配。新授权不接收 `scope` 等范围字段；旧范围记录保留但不生效，不自动升级为全站权限，需明确重新授权。本人接口返回有效权限，导航与业务服务同步使用有效权限；审核决定同时检查任务分配。
- MFA：验证器绑定、登录二次验证、一次性恢复码、密码与验证器重新认证、禁用与换绑前置验证、会话轮换及其他设备撤销。种子用独立 Fernet 密钥加密，恢复码只存摘要；TOTP 拒绝重放。生产环境的授权、发布、权益、定价、结算及付款等敏感写操作要求近期 MFA。密码找回保留验证器并使旧恢复码失效。
- 协议和价格状态通知：通知另一签约方/有职责权限的平台人员，排除操作人，不携带条款、哈希或金额。补协议确认、本人价格方案查询/确认/否决、本人结算确认/明细异议、后台结算和付款登记/核对页面。
- 付款结果不确定时持续占款，允许凭真实证据在原尝试上继续核对为成功/失败；不得另建尝试绕过不确定状态。页面不会发起外部转账。
- SSE 每次心跳复查会话撤销、到期及账号状态；无效即断开，只推计数；连接数限制仍是进程级。
- 自动保留期清理接入现有事务函数，默认关闭；扫描、派生、通知、AI 分队列，提供可选 Worker 隔离 Compose 文件。
- 审计导出写入审计失败时不下发文件；登录回跳拒绝跨站、反斜线与编码绕过；服务端获取模块增加 `server-only`，生产浏览器 Source Map 关闭，公开产物扫描接入 CI；基础 CSP 限制对象嵌入、页面嵌入、base 与表单来源。
- PostgreSQL 本地备份/恢复工具：不覆盖现有备份，SHA-256 校验，恢复需重复目标库名，单事务恢复且不使用 `--clean`，不重放外部付款。
- 修复后端 Docker 上下文曾排除迁移版本目录的问题；Worker 镜像默认队列与 Compose 对齐，前端镜像构建执行公开产物检查。真实镜像构建仍待 Docker 环境验收。
- 修复运行依赖漏洞并将后端清单对齐本次验证版本；派生处理器升级为 `derive/3`，保留历史文件与派生记录。

## 升级与使用

1. 停止写入并备份数据库、私有对象、配置及独立 MFA 密钥；核对旧派生任务和待重试任务。原件、账本和历史记录不自动清理。
2. 安装新清单与锁文件，执行 `alembic upgrade head`，确认到 `0013_v002_mfa` 后再启新 API/Worker。先升级约束，后开启产生新枚举值的代码。
3. 配置私密的 `MFA_ENCRYPTION_KEY`；管理员在账号安全页绑定并保存一次性恢复码。密钥必须独立备份；不要换空密钥来关闭 MFA。
4. Worker 默认消费全部新队列；需要进程隔离时叠加 `docker-compose.workers.yml`。仅 `ai` profile 启动 AI Worker 不代表允许模型调用。
5. `RETENTION_SCHEDULE_ENABLED=false` 保持不自动清理，政策确认后才启用。`COMMERCE_ENABLED=false`、合规门槛关闭、`AI_ENABLED=false` 保持默认。
6. 原有范围权限不自动转全站。管理员核对职责后重新授予；维护范围继续使用课程/资源分配。新授权请求不再接受 `scope`、`scope_catalog_id`、`scope_resource_id`。

`0013` 降级前必须经已认证流程禁用已启用的 MFA；`0012` 不能在仍有新枚举值的数据上静默收窄约束。不要为了降级删除审计、业务或财务记录。

MFA 算法依据 [RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)，种子加密使用 [Fernet](https://cryptography.io/en/latest/fernet/)。这不构成生产安全认证。
